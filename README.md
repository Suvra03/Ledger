# Ledger
Personal finance tracker for multiple savings accounts — daily calendar heatmap, category reports, phone+password login, PIN/Face ID app lock. Next.js + Supabase.


A personal finance tracker built for tracking multiple savings accounts in one place.

- Log income, expenses, and transfers across all your accounts
- See daily spending on a calendar heatmap
- Category and account breakdowns with charts
- Phone number + password login, with email-OTP password reset
- PIN and Face ID / Touch ID app lock

Built with Next.js, Supabase, and Tailwind CSS. Deployed on Vercel.
